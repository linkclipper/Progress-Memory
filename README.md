# LinkClipper Progress-Memory

Organizational continuity: what shipped, what's in flight, what's blocked, what's next — so any session (and any future contributor) resumes with zero archaeology. Read `STATUS.md` first; the monthly files are the audit trail.

## Layout

| File | Contents |
|---|---|
| `STATUS.md` | The current snapshot — always the single most-recent truth |
| `2026-11.md` | Monthly ledger for the current month (append, don't rewrite) |

Rules: update `STATUS.md` and append to the month file **at the end of every working session** that changes anything real (code, release, docs, milestone). Blocked items live with their unblock condition, not in prose.
